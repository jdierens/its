# Product page

Every item has an optional product page URL in `items.product_url`. It is empty until someone enters one. The item form asks for an `http` or `https` address. A blank value clears it. On the item page, a valid address opens in a new tab from an icon in the field.

Search matches the URL along with the SKU, name, model, part number, OEM name, and OEM part number. The items table shows it after OEM part number, and that cell edits in place. Export and CSV include a Product page column in that same place.
