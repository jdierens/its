- A purchase order can be saved as a draft, approved, printed, and cancelled. A draft keeps a blank number. Approve assigns POxxxx, one past the highest number already used, unless another free number is typed, and marks the order open.
- Print uses the sales-order letter sheet, titled PURCHASE ORDER, without the terms page. Cancel stays available until the order is cancelled or closed. A number already assigned stays used.
