- ITS can be installed on a phone. The manifest and icons cover Android Chrome and iOS Safari. The service worker keeps the app shell only. Inventory is not stored on the phone, and nothing is queued to write later.
- The items list and the item page fit a phone width. Scan is a new page. It reads an item QR code, a Code 128 SKU, or a bin code such as 20000-P and opens that item or bin.
- The camera uses BarcodeDetector where the browser has it, and ZXing everywhere else, including iOS Safari. A handheld scanner works from any page when it types the code and presses Enter outside a text field.
- Take photo on an item opens the phone camera. Add images is a file picker and does not. Large photos are reduced before upload. The new photo follows the existing order, and the editor is one tap away.
